Analysis Cohort

master comes from the shared pipeline. Throughout this analysis:

  • Exposure: etoh_hepatitis - alcoholic hepatitis (AH) vs. non-AH
  • Primary outcome (event of interest, cause = 1): death within 90 days
  • Competing risk (cause = 2): liver transplant within 90 days
  • Censoring (cause = 0): alive and not transplanted at 90 days / lost to follow-up

Time and status come from the shared pipeline variables time_to_death_90days_cmp / time_to_death_status_90days_cmp (0 = censored, 1 = death, 2 = transplant).

Show cohort filter 
# Cause coding for the competing-risk event factor `event_cmp`:
#   level 1 "Censored"   -> censoring        (numeric code 0)
#   level 2 "Death"      -> OUTCOME OF INTEREST (numeric code 1)
#   level 3 "Transplant" -> COMPETING RISK   (numeric code 2)
# This ordering matters: tidycmprsk::crr() treats the first level as the
# censoring code, and `failcode` selects which remaining level is the cause
# of interest (all other non-censoring levels become competing risks).
analysis <- master %>%
  filter(!is.na(etoh_hepatitis)) %>%
  mutate(
    etoh_hepatitis = factor(etoh_hepatitis, levels = c(0, 1), labels = c("Non-AH", "AH")),
    event_cmp      = factor(time_to_death_status_90days_cmp,
                            levels = c(0, 1, 2),
                            labels = c("Censored", "Death", "Transplant"))
  )

Show unadjusted Fine-Gray 
# Aalen-Johansen non-parametric CIF (used for both the plot and the day-90 estimates below)
ci_unadj <- cuminc(
  Surv(time_to_death_90days_cmp, event_cmp) ~ etoh_hepatitis,
  data = analysis
)

p_unadj <- ci_unadj %>%
  ggcuminc(outcome = "Death") +
  labs(
    title    = "Unadjusted 90-day cumulative incidence of death",
    subtitle = "AH vs. non-AH",
    x        = "Days from terlipressin initiation",
    y        = "Cumulative incidence  -  Death",
    caption  = "Outcome: death (cause 1)  |  Competing risk: liver transplant (cause 2)"
  ) +
  add_confidence_interval() +
  add_risktable(
    risktable_stats  = c("n.risk", "cum.event"),
    stats_label      = list(n.risk = "At risk", cum.event = "Events"),
    risktable_height = 0.30,
    size             = 3.2,
    theme = theme_risktable_default(
      axis.text.y.size = 9,
      plot.title.size  = 10
    )
  ) +
  scale_x_continuous(
    breaks = seq(0, 90, by = 30),
    limits = c(0, 90),
    # Push the day-0 column ~3 days inside the panel so the leftmost
    # numbers don't overlap the "At risk" / "Events" row labels.
    expand = expansion(add = c(3, 1))
  ) +
  theme(
    plot.caption = element_text(face = "italic"),
    plot.margin  = margin(5, 10, 5, 15)   # extra left margin
  )

save_plot_pptx("unadjusted_cif", p_unadj,
               "Unadjusted 90-day cumulative incidence of death (AH vs. non-AH)")

Binary logistic regression - HRS overall response

Two multivariable binary logistic regression models for overall HRS response (hrs_responders_cat_2, 1 = responder / 0 = non-responder). Odds ratios with 95% confidence intervals.

Model 1: age + sex_male + etoh_hepatitis + aclf_grade

Outcome: hrs_responders_cat_2 (1 = responder, 0 = non-responder). Predictors: age, sex_male, etoh_hepatitis, aclf_grade (0-1, 2, 3; reference = 0-1).

NoteACLF grade 0 merged into grade 1

In this model, ACLF grades 0 and 1 are combined into a single reference category (ACLF 0-1). Every patient with ACLF grade 0 (n < 11) was an HRS responder, so with grade 0 as its own reference level the model could not estimate the grade 1-3 odds ratios (complete separation; they appeared as OR 0.00 with no confidence interval). The Fine-Gray models are unaffected; they use aclf_grade as a continuous term.
